# 2.1 — Pocket TTS with "Heart" (plan)

Owner, 2026-10-29: replace Kokoro with Pocket TTS, with af_heart cloned into "Heart". 2.1 also brings the Estia
One connection, which comes **after** this. Estia (local-assistant, `tiffany` branch, `tools/voice/`, shipping in
0.9.8) already runs Pocket; this plan borrows its measured decisions rather than re-deriving them.

## What Estia settled (don't re-derive)

- **Engine:** Kyutai's Rust `pocket-tts` 3.3.0 (release v4.0.1, aarch64-apple-darwin, MIT), one process **per
  line**: `generate -q --quantize --config <yaml> --voice <state>.safetensors --text - --output-path -`, env
  `RAYON_NUM_THREADS=1 HF_HUB_OFFLINE=1`. CPU, int8. Output: 24 kHz mono 16-bit WAV on stdout — the format
  `AudioPlaybackEngine` already plays, no resampling.
- **Why one-shot:** the release has no resident mode; its `serve` mode is a web server (CORS for kyutai.org, fetches
  voices from the web); the resident Python package was slower on 4 of 5 lines. Measured on the mini, 24 Oct:
  **123–374 ms per sentence, model load included** (Python resident: 90–601 ms).
- **Model:** `kyutai/pocket-tts-without-voice-cloning` (not gated), english weights `a7056f5` (219 MB), tokenizer
  `00eac05` (245 KB), each pinned by sha256. Hugging Face reachable from this laptop (fetched 2026-10-29).
- **Heart:** af_heart audio (Kokoro-82M, Apache 2.0) cloned with Kyutai's **gated** cloning model
  (`kyutai/pocket-tts` @ `db04f0e6`, CC BY 4.0), exported by 3.3.0's `export-voice`: `heart.safetensors`,
  8,652,024 bytes, sha256 `60e5e6cb…5425`, gain **+1.0 dB** to match af_heart. **100M model only** — on the 18M
  the question-end rise is lost (−0.1 st vs +3.2). Measured (Praat): pace 4.6 words/s vs af_heart 4.0.
- **Runaway:** a long stretch with no pause mark (~400 reading-chars on the 18M) garbles to the time budget with a
  clean exit — nothing reports failure. Guard: insert commas into stretches over 200 (`PocketPace`), cap run time
  at `2 s + 10 ms/char`, cap output at 16 MB.
- **Never silence:** whatever Pocket can't say (not downloaded, refused file, failed/late run) Kokoro says
  (af_heart). Three failures in a row rest it (1, 5, 30 min).
- **Sandbox per run:** `sandbox-exec` — no network, no fork/exec, no writes, reads only its own folder.
- **No speed parameter.** Pocket speaks at its own pace; Estia passes none.
